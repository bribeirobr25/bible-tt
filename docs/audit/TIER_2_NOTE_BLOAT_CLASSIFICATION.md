### 3.3 Methodology disclosure

The original Step 1b plan called for §734 classification at classification-doc time. This session used a keyword **heuristic** as Step 1b (faster but over-flags) and applied the strict §734 review at Step 2 execution time. This worked — the 6 real relocations match the Gen 9 pilot's quality — but the classification doc was initially generated with the heuristic-only verdicts. This §3 annotation reconciles the two: heuristic output preserved as a STARTING POINT, with Step 2 outcomes layered on top.

**For future sessions**: applying strict §734 BEFORE writing the per-chapter table is preferable. The heuristic remains useful as a coarse filter to find candidates worth inspecting, but the RELOCATE decision should come from per-note §734 review, not from heuristic triggers alone.
