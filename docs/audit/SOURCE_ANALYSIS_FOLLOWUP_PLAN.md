## Decision questions (please audit)

### Q1 — *betoch* Tier-1 wording
- **A (recommended):** "**within the waters**" (single, clean). EN/PT "dentro das águas"/ES "dentro de las aguas"; DE "innerhalb der Wasser".
- **B:** "inside the waters".
- **C:** slash "within/inside the waters".

*Recommendation: A. A slash (C) is reserved for genuine **source-text** ambiguity (Rule 2); "within/inside" are English synonyms of one Hebrew sense, so a slash would misuse the convention. Pick one clean word and let a Tier 2 note carry the nuance.*

### Q2 — *mavdil* Tier-1 wording

*Recommendation: A, same slash reasoning as Q1 ("separator/divider" are English synonyms, not source ambiguity). The v6 note carries "divider" + the grammar ("Hiphil participle used substantivally"). DE wording confirmed by the DE editor before commit.*
