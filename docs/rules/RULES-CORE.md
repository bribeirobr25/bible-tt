## MISSION STATEMENT

This translation does not replace the source text. It is a disciplined attempt to show, in English, Brazilian Portuguese, German, and Spanish, what the source text says, what it may mean, and where it remains open. Where ambiguity exists, it will be preserved or signaled. Where additions are necessary, they will be marked. Where choices are uncertain, notes will say so.

**This is not the closest translation to the original—it is the least dishonest version we could build.**

---

## PRIME DIRECTIVE (Non-Negotiable)

1. **Do not simplify what the source text keeps complex.**
2. **Do not clarify what the source text leaves ambiguous.**
3. **Do not add what the source text does not say** (unless target grammar absolutely requires it).
4. **When addition is unavoidable, signal it clearly.**

**If any rule conflicts with this principle, the principle wins.**

---

## OUTPUT STRUCTURE: THREE-TIER SYSTEM

Every translated passage organized in three layers:

### **Tier 1: Main Translation**
- Primary reading text
- Readable but visibly faithful to source text
- **KEEP MAIN TEXT CLEAN:**
  - No inline commentary
  - No parenthetical mini-glosses
  - No explanatory prose in the line
  - **Limited ambiguity slashes ARE permitted** for a very small set of governed high-stakes terms (e.g., wind/spirit, side/rib, desire/turning, bruise/strike). These are governed by the locked glossary and Rule 2; they are not ad-hoc.
- Minimal smoothing
- This is what most readers see

### **Tier 2: Essential Notes**
- Maximum 3-5 notes per verse (default)
- Each note 1-2 sentences maximum (default)
- **Pivotal-verse exception:** Verses with extraordinary textual density may carry 5-7 notes — but ONLY if: (a) the verse is logged as "pivotal" in the editorial log, (b) each note remains essential (not commentary), and (c) anything beyond core clarification moves to the companion file. This is a governed exception, not a loophole.
- **ENHANCED VISIBILITY THROUGH DESIGN:**
  - Use boxed/highlighted format
  - Color-coded icons (🔴 Critical, 🟢 Lexical, 🔵 Grammatical, 🟡 Theological)
  - Placed immediately after verse (not at chapter end)
  - Bold source-language terms
  - Clear visual hierarchy
- Only for features that would otherwise disappear:
  - Ambiguity
  - Unusual grammar
  - Wordplay
  - Transliterated terms
  - Culturally loaded concepts
  - Uncertainty levels

### **Tier 3: Appendix/Study Layer** *(Optional - not required per verse)*
- Source-language text + transliteration
- Literal word-for-word gloss
- Full linguistic analysis
- Pattern tracking across verses

## THE 29 RULES

### **I. SEMANTIC RULES (Meaning & Words)**

#### **Rule 1: Controlled Lexical Consistency**
Same source word → Same base translation **by default**

**Policy:**
- Follow locked glossary (per source-language supplement)
- Contextual shifts allowed when **clearly required by immediate context**
- **All shifts must be justified** in editorial log
- **Public notes** explain shifts only when reader needs to know

**Why:** Consistency reveals patterns; controlled flexibility prevents rigidity. **Uncontrolled lexical drift is the main risk vector in this system.**

---

#### **Rule 2: Preserve Ambiguity**
If the source text supports 2+ meanings and context doesn't force one choice, preserve both

**Decision Tree:**
```
Source word has multiple meanings?
├─ NO → Use single best translation
└─ YES ↓
    Context clearly resolves?
    ├─ YES → Use resolved meaning
    └─ NO ↓
        Both meanings matter to text?
        ├─ NO → Use primary meaning + note alternative
        └─ YES ↓
            Can limit to 2 options in main text?
            ├─ YES → Use slash (see source-language supplement for governed terms)
            └─ NO → Choose 2 most important, note rest
```

**Slash Policy:**
- Maximum 2 options in main text
- Third option → footnote

---

#### **Rule 3: Avoid Imported Theology**
Don't sneak in later religious concepts not justified by immediate source-text context

**Test:** Would an ancient reader of the source text hear this theological meaning?
If NO → don't import it

**Corollary — Restraint matters both ways:**
The same discipline that forbids importing later theology also forbids importing anti-traditional reaction as if unfamiliarity equals originality. Choosing the less-familiar reading simply *because* it is less familiar is as dishonest as smoothing. Ambiguity means ambiguity — not reflexive novelty.

See source-language supplement for language-specific theological overlay tables.

---

#### **Rule 4: Transliterate Strategic Terms**
Keep source-language terms when translation imports false connotations

**When to Transliterate:**
1. No accurate target-language equivalent exists
2. Common translation carries misleading baggage
3. Term is structurally/cosmologically critical

**Format:** *Italicize* + define in footnote once

See source-language supplement for current transliterated terms.

---

### **II. STRUCTURAL RULES (Grammar & Form)**

#### **Rule 5: Respect Source Grammar**
Preserve grammatical features when readable; adjust minimally when not

**What to Keep:**
- Repetition patterns
- Unusual constructions
- Missing pronouns (don't auto-add)
- Gender agreements (especially in Portuguese, German & Spanish)
- "Between...and between..." patterns
- Fronting for emphasis

**What to Adjust:**
- Word order when incomprehensible
- Verb-subject position when archaic

**Balance Test:** Structure preserved + comprehensibility maintained

---

#### **Rule 6: Preserve Poetic Doubling & Repetition**
Source texts double roots and pair synonyms for artistic effect — keep it

**Note:** Yes, it sounds odd. That's intentional poetic style.

See source-language supplement for specific doubling examples.

---

#### **Rule 7: Preserve Parallel Structure**
Lock formula **pattern**, not necessarily identical wording in all cases

**Policy:** Keep formulas stable across repeated occurrences unless meaningful source-text variation requires a documented change.

See source-language supplement for locked formula patterns per book.

---

### **III. VERB RULES (Action & Tense)**

#### **Rule 8: Reflect Verb Nuance**
Source verbs ≠ target-language tenses; preserve meaningful distinctions

**Source-specific implementation:**

### **IV. TONE & TRANSPARENCY RULES**

#### **Rule 10: Neutral Formal Register**
Slightly elevated, clear, serious — avoid both extremes

**Target Register:**
- Formal enough for serious literature
- Clear enough for modern readers
- Not archaic, not casual

**English:**
```
✗ "And God spake" (archaic)
✓ "And God said" (neutral formal)
✗ "Then God was like" (too casual)
```

**Portuguese:**
```
✗ "E disse o Senhor Deus" (overly biblical when not in source)
✓ "E Deus disse" (elevated but natural)
✗ "Aí Deus falou" (too colloquial)
```

**German:**
```
✓ "Und Gott sagte" (elevated neutral - RECOMMENDED)
✓ "Und Gott sprach" (alternative, slightly more elevated)
✗ "Dann sagte Gott" (too casual)
✗ "Da sprach Gott" (too Luther-esque if used rigidly)

GERMAN POLICY: Elevated but contemporary German
- NOT Luther Bible archaisms as default
- Standard educated German of 2020s
```

**Spanish:**
```
✗ "Y dijo Jehová Dios" (archaic Reina-Valera register)
✓ "Y Dios dijo" (elevated but natural)
✗ "Entonces Dios va y dice" (too colloquial)

SPANISH POLICY: Elevated contemporary pan-Hispanic neutral Spanish
- NOT Reina-Valera archaisms as default
- No voseo, no vosotros — neutral register throughout
- Standard educated pan-Hispanic Spanish of 2020s
```

#### **Rule 11: Signal All Additions**
Mark words not in source text; distinguish types of additions

**Three-Part System:**

**A. Italics:** For minimal grammatical additions in main text

**B. Brackets:** For rare clarifications in main text (use sparingly)

**C. Notes/Gloss:** For untranslatable particles

**Policy:** Don't clutter main translation with grammar labels — that's what notes and gloss are for

See source-language supplement for specific addition examples.

---

#### **Rule 12: Avoid False Precision**
Don't invent details the source text leaves vague

**Test:** Is this detail **in the source text** or **in my interpretation**?

See source-language supplement for specific examples.

---

#### **Rule 13: Uncertainty Levels**
Every note about difficult terms should indicate confidence level

**Three Levels:**

| Level | Definition | When to Use |
|-------|-----------|-------------|
| **Probable / Provável / Wahrscheinlich / Probable** | Strong evidence, wide scholarly agreement | Standard translations |
| **Possible / Possível / Möglich / Posible** | Reasonable option, debated among scholars | Alternative views |
| **Uncertain / Incerto / Ungewiss / Incierto** | Genuinely unclear, multiple valid theories | Rare/unique words |

**Prevents false confidence in notes across all languages.**

These three levels apply to Tier 2 translation notes. For Tier 3 companion files, see Rule 29's extended confidence schema (adds VERIFIED, SPECULATIVE, and DOCUMENTED).

See source-language supplement for specific examples.

### **V. ADVANCED COORDINATION RULES**

#### **Rule 14: Annotate Wordplay**
Mark source-text puns, paronomasia, and sound-play

**When Translatable:** Preserve in main text if possible; note the wordplay.
**When Untranslatable:** Translate meaning literally; note: "Source-text wordplay cannot be rendered."

**Cross-Reference Policy:**
- **Lexical / formulaic cross-references** (same word, formula, or direct echo): **uncapped**, but documented.
- **Interpretive cross-references** (thematic similarity without lexical link): **capped at 0–2 per verse** in Tier 2. Must be logged.

---

#### **Rule 15: Three-Output Rule**
Each verse should ideally produce three forms (reduces pressure on single line)

**A. Main Translation** (Tier 1) — Readable, disciplined
**B. Literal Gloss** (Tier 3 - optional) — Word-for-word
**C. Essential Notes** (Tier 2) — Explains difficult choices, 1-2 sentences each, uncertainty levels marked

#### **Rule 16: Cross-Language Alignment**
Multilingual project requires consistency verification across all target languages

**Quadrilingual Alignment Checklist (EN ↔ PT ↔ DE ↔ ES):**
- [ ] Same lexical choices from glossary?
- [ ] Same ambiguity policy (slash placement)?
- [ ] Same formula structure?
- [ ] Same interpretive restraint?
- [ ] Same additions marked?

**Gender Awareness:**
- Portuguese, German & Spanish preserve grammatical gender; English doesn't
- When gender could be misread theologically, note: "Grammatical gender, not ontological"

**Cross-Supplement Glossary Alignment:**
When the same concept appears in both HB and GS source texts (e.g., Hebrew *ruach* / Greek *pneuma*), target-language renderings must coordinate across supplements. The HB glossary decision governs; GS glossary must justify any divergence in the editorial log.

**DIVERGENCE POLICY:**
When one language must diverge from others due to grammatical requirements:
- Document reason in editorial log
- Ensure divergence is grammatical, not interpretive
- Verify other three languages remain aligned where possible

**If any language drifts into paraphrase, pull it back.**

See source-language supplement for language-specific gender tracking.

---

#### **Rule 17: Definite Article Consistency**
Translate source-text article consistently

**Basic Rule:**
- Source text has article → target language has article
- Source text lacks article → don't add (unless target idiom requires)

**Exception: Proper Names**
- Article may mark a term becoming a proper name. Flag the shift in a note.

**Absence Matters:**
When source text **lacks** article where expected, preserve or note the absence if meaningful.

See source-language supplement for article system specifics per source language.

---

#### **Rule 18: Numbers & Ordinals**
Preserve cardinal vs. ordinal distinction

**Why it matters:** Day 1 is treated differently linguistically — this is significant.

See source-language supplement for specific examples.

---

#### **Rule 19: Priority Order When Rules Conflict**

**When Rules Conflict, Follow This Order:**

1. **Preserve meaning** (most important)
2. **Preserve ambiguity** (when source is ambiguous)
3. **Preserve structural pattern** (formulas, repetition)
4. **Preserve lexical consistency** (glossary)
5. **Preserve readability** (don't break language)

---

#### **Rule 20: Capitalization**
Don't capitalize interpretive terms beyond what the source text justifies

**Standard Policy (English, Portuguese & Spanish):**
- **Lowercase** for common nouns (even theologically significant ones)
- **Capitalize** only proper names and sentence beginnings
- Don't use capitalization to import theology

**GERMAN EXCEPTION:**
German capitalizes **ALL nouns** grammatically (Substantive), not for theological emphasis.

**German Capitalization Policy:**
- German's grammatical noun capitalization is **PERMITTED** as it's a language requirement, not theological import
- **NO additional emphasis through GROSSBUCHSTABEN (all caps)**
- **NO capitalization of adjectives or other parts of speech for emphasis**

**Example:**
```
German: "der Geist Gottes" - both nouns capitalized grammatically
English: "the spirit of God" - lowercase unless proper name
Portuguese: "o espírito de Deus" - lowercase unless proper name
Spanish: "el espíritu de Dios" - lowercase unless proper name (same policy as EN/PT)
```

---

#### **Rule 21: Don't Smuggle Commentary into Main Text**
Translation ≠ commentary in disguise

**Policy:**
If interpretive nuance, historical background, or cosmological explanation cannot fit cleanly in main line **without overloading it**, move to notes.

**Main text must remain translation, not embedded commentary.**

---

#### **Rule 22: Text-Critical Restraint**
Translate the established base text; note variants, don't silently adopt them

**Base Text Policy:**
The default base text for this project is declared per source-language supplement (see RULES-HB.md, RULES-GS.md).

**Policy on Variants:**
- Significant textual variants may be **noted** in Tier 2 or Tier 3
- Must **not be silently adopted** in main text

**No-Harmonization Principle:**
Translation of a verse must be governed first by its **immediate context** and **book-level patterning**, not by later canonical harmonization or doctrinal back-reading.

Each verse answers to its own text first. Cross-canonical resonance belongs in notes (Tier 2) or appendix (Tier 3), never in the main translation.

See source-language supplement for specific no-harmonization examples.

---

#### **Rule 23: Genre Sensitivity**
Patterns specific to one genre or book should not mechanically colonize others

**Policy:**
- Different genres (liturgical, narrative, poetry, prophecy, epistle) may need different transparency strategies
- Repetition, rhythm, and lexical consistency remain important across genres
- Genre shifts must be respected

See source-language supplement for book-specific genre notes.

---

#### **Rule 24: Edition Identity**
Every published rendering must declare its edition type

### **TRANSPARENT EDITION**
**Purpose:** Maximum linguistic visibility of source-text features
- Prioritizes source-text structure and compression
- Slight awkwardness acceptable when mirroring source text
- Root doubling, repetition, unusual constructions maximally preserved
- Minimal smoothing

**Target Audience:** Serious students, scholars, those studying source-text patterns

### **READER EDITION**
**Purpose:** Accessible reading while maintaining honesty
- Same locked glossary, same ambiguity preservation, same notes system
- Slightly smoother syntax where target grammar requires
- Readability priority within honest constraints

**Target Audience:** General readers seeking accurate but readable translation

**ANTI-DRIFT SAFEGUARD:**
Reader Edition may smooth syntax and punctuation.
Reader Edition may **NOT** smooth away: ambiguity (Rule 2), passive voice, cardinal vs. ordinal distinction (Rule 18), root doubling, discourse structure, or theologically open wording.

**BOTH EDITIONS SHARE:** Locked glossary, ambiguity preservation, no theological smoothing, same notes, same base text, same uncertainty levels, same quality control.

**Cross-source edition clarity:** Edition choice (Transparent/Reader) is declared per source-language scope. A project may ship HB Transparent + GS Reader if declared explicitly in front matter.

**PRESENTATION LAYERS:**
A single edition MAY be presented in two layered views within one chapter file:
- **Continuous Reading** — verses flow as prose with superscript verse numbers
- **Verse-by-Verse Study** — per-verse heading, main text, boxed notes inline

Both views present **identical text**. Presentation layers are views of a single edition, not a third edition type.

- Variant traditions may be noted but not silently adopted
- Citation format follows the source text's own apparatus conventions

#### **Rule 27: Inclusive & Gendered Language**
Source texts have grammatical gender; target languages handle it differently. The translator must distinguish **grammatical gender** from **referential gender** from **interpretive gendering**.

**Core principles:**

**A. Generic terms for humanity:** Default rendering uses gender-neutral terms. Gendered terms only when the text contrasts gendered pairs.

**B. Gendered pairs:** Render as gendered pair when the source text uses a gendered pair.

**C. Biological-pair terms:** Render directly (e.g., "male and female"). Do not substitute social-pair terms.

**D. Grammatical-gender mismatches:** Tracked in editorial log per source-language supplement. A note is required only when the mismatch is theologically or referentially loaded.

**E. Pronouns for the divine:** Source texts use masculine grammatical forms for the divine. This is grammatical, not ontological. Retain masculine pronouns where source grammar forces them.

**F. Collective singulars:** Follow source-text grammatical agreement in main text. Note must flag collective scope. Do not capitalize for theological individuation.

See source-language supplement for language-specific gender examples.

#### **Rule 28: Review & Sign-off Workflow**
No verse ships without documented review.

**Required reviewer roles per verse:**

| Role | Qualification | Responsibility |
|------|---------------|----------------|
| **Source-language scholar** (Hebraist for HB, Hellenist for GS) | Reading proficiency in source language; access to critical apparatus | Verifies main-text faithfulness; signs off on glossary and ambiguity |
| **Target-language editor** (one per language: EN, PT, DE, ES) | Native or near-native; familiarity with target literary register | Verifies Rule 10 register, Rule 11 additions, Rule 18 numbers, idiomatic correctness |
| **Cross-alignment reviewer** | Reads all target languages | Runs Rule 16 checklist; signs off on consistency |
| **Project lead** | Final accountability | Resolves disagreements; authorizes exceptions |

**For AI-assisted drafting:**
- Each AI-assisted verse must record: model identifier, version, date, prompt summary, and human-reviewer decision.
- AI cannot occupy a reviewer role. AI output is a draft, not a sign-off.

**Until reviewer roles are filled:** verses marked `provisional — pending review`.

**Status taxonomy** (`provisional | reviewed | signed-off`) applies to ALL content types: chapter files, companion files, introduction files, prophecy files, and people files. Reviewer requirements may vary: prophecy and people files require source-language-scholar review for textual claims; historical and genealogical claims may be cleared by a target-language editor with relevant credentials. Cross-alignment review is mandatory for all files when target-language versions are added.

#### **Rule 29: Contextual and Comparative Study Material**

Contextual enrichment may be included **only** in Tier 3 companion files or clearly separate resources. Never in Tier 1. Only minimally in Tier 2 (as cross-references governed by Rule 14).

**Location:** Companion files at `{locale}/{book}/study/CHAPTER-{N}-CONTEXT.md`

**Core constraint:** Enrichment presents what the text says, what other sources say, and what remains unknown — then stops. **The reader draws conclusions. The enrichment draws none.**

**Dual-Label System:**
Every contextual claim carries two labels:

*Claim-type tag:* TEXTUAL | STRONG INFERENCE | POSSIBLE INFERENCE | COMPARATIVE PARALLEL | LATER RECEPTION | HISTORICAL / ARCHAEOLOGICAL | SCIENTIFIC COMPARISON | SPECULATION

*Confidence level:* VERIFIED | PROBABLE | POSSIBLE | UNCERTAIN | SPECULATIVE | DOCUMENTED

DOCUMENTED is for LATER RECEPTION entries where the tradition is historically attested. It is distinct from VERIFIED (textual fact) — DOCUMENTED means "this reception tradition exists and is well-attested," not "the interpretation is textually correct."

**Companion file sections (A–H) — AVAILABLE, NOT ALL MANDATORY:**
- **A.** Source Text Features Exposed by TT
- **B.** Ancient Parallels
- **C.** Historical and Archaeological Context
- **D.** Linguistic and Philological Deep Dives
- **E.** Scientific Correspondence and Non-Correspondence
- **F.** Later Reception in Other Traditions
- **G.** Curiosities and Open Questions
- **H.** Sources Consulted — **MANDATORY**

**Companion File Research Checklist:**

When composing a companion file, systematically research each applicable category below. Route findings to the appropriate section. Not every category applies to every chapter — include only when there is substantive, sourced content.

*Historical & Social Context (→ Section C):*
- Calendar and timekeeping: What calendar system was in use? What time of year does the narrative suggest? (Note: calendar systems applicable to the book's narrated period belong in the book introduction Section D. Per-chapter notes should reference the introduction, only adding chapter-specific calendrical observations.)
- Social customs and daily life: What customs, norms, or daily-life details illuminate the text? (e.g., water-drawing times, hospitality obligations, mourning practices, marriage customs, honor-shame dynamics)
- Political context: What political relationships, tensions, or power structures are relevant? (e.g., Jewish-Samaritan relations, vassal-suzerain dynamics, imperial occupation)
- Economic context: What economic system, trade routes, or material conditions are relevant?
- Legal context: What legal systems, customs, or codes are relevant? (e.g., ANE law codes, Roman law, Sanhedrin procedures)
- Geographic context: What geographic features, distances, travel routes, or regional characteristics matter?

*External Attestation (→ Section C):*
- Non-biblical attestation: Do independent historical sources mention people, places, or events in this chapter? (e.g., Tacitus, Josephus, Suetonius, Mara bar Serapion, inscriptions, seals)
- Archaeological artifacts: Are there physical objects (inscriptions, tablets, seals, buildings) corroborating or illuminating the text? Where are they today?
- Epigraphic evidence: Are there inscriptions or written records from the same period and region?

*Linguistic & Philological (→ Section D):*
- Etymology and wordplay
- Rare or disputed vocabulary
- Cross-language comparison

*Scientific Correspondence (→ Section E):*
- Astronomical correlation: Do astronomical events (eclipses, conjunctions, comets) correlate with narrated events? Cross-reference with the calendar system in use.
- Geological/geographical observation: Do geological features (fault lines, mineral deposits, flood layers, salt formations) correlate with described events?
- Biological/medical observation: Do biological or medical facts illuminate the text? (e.g., blood as life-carrier, childbirth, disease, plant biology)
- Scientific status labeling: For scientific claims referenced in companion entries, the existing 6-tier confidence schema applies. The confidence label refers to the level of scientific consensus, not metaphysical certainty. Both mainstream and minority scientific positions must be described in their own terms before being labeled. The label states the consensus level, not the merit. This prevents both false parity (presenting fringe positions as equal to established science) and dismissiveness (ignoring legitimate debate). The TT presents; the reader assesses.

*Later Reception & Tradition (→ Section F):*
- Jewish reception: How do rabbinic, Talmudic, or medieval Jewish sources read this passage?
- Christian reception: How do patristic, medieval, or modern Christian traditions read it?
- Islamic reception: How does the Quran or Islamic tradition treat parallel material?
- Philosophical/secular reception: Has this passage influenced philosophy, ethics, law, literature, or art?

*Supernatural/Miraculous Claims (→ Section A for textual, Section G for open questions):*
- What does the text claim happened? (state neutrally)
- Are there comparable claims in other traditions? (→ Section B)
- What are the scholarly positions on the claim? (various confidence levels)
- What remains genuinely open? (→ Section G)

*Cross-Chapter & Cross-Book Connections:*
- Does this passage quote, echo, or allude to earlier passages?
- Is this passage quoted or alluded to later in the same book or in other books?
- Are there thematic chains (e.g., blessing/curse, covenant, exile/return) that pass through this chapter?

**Cross-book topical threads:** When a topic spans multiple books (e.g., death-introduction, covenant-progression, messianic-expectation), use anchor-and-reference structure:
- Primary anchor entry in the most foundational book's companion (e.g., death-scope anchor in Gen 3 G9)
- Reference entries in subsequent books point back to the anchor ("See Genesis 3 G9 for primary discussion")
- The anchor entry may be updated when later books contribute substantially — updates must be logged

**Section H source provenance:** For each cited source, indicate provenance: PEER-REVIEWED (journal article, university press, recognized critical edition), ACADEMIC POPULAR (trade book by credentialed scholar), POPULAR (non-academic author), or PRIMARY (ancient document, inscription, artifact). Popular sources may be cited to document HOW a tradition is read or argued (LATER RECEPTION — DOCUMENTED), but cannot serve as evidence FOR or AGAINST the textual claims they discuss.

**Mandatory disclaimer** at top of every companion file.

**Readability standard:** Companion content in Explore and Context views must be accessible to a general reader without academic background. Avoid: Latin terms without explanation (e.g., use "direct command" not "fiat"), formal/archaic vocabulary when a common word exists (e.g., use "doesn't have" not "lacks/carece"), and complex sentence structures that require re-reading. Technical terms from Hebrew, Greek, or scholarly fields should be briefly glossed on first use. The goal: a curious person who has never studied theology or ancient languages can read any companion entry and understand what it says.

**Tracing popular content to source.** When evaluating claims from social media, popular books, or short-form video: (a) identify the underlying scholarly work, denominational document, or ancient text — cite the source, not the social-media derivative; (b) document with provenance label (PEER-REVIEWED / ACADEMIC POPULAR / POPULAR / PRIMARY); (c) distinguish what the source claims from what popular amplification adds; (d) apply Rule 3 corollary symmetrically — neither dismiss the tradition because of overclaim, nor adopt the overclaim because the tradition is real; (e) place in the appropriate companion section (F for reception, E for science, Prophecy view for prophecy); (f) refuse the amplification's overclaim.

**Quadrilingual implementation:** EN-first pilot; PT-BR, DE, and ES after pilot review.

**Prophecy Tracking Files:**

Prophecy files catalog prophetic statements, their context, and their fulfillment status across traditions.

**Location:** `{locale}/{book}/study/CHAPTER-{N}-PROPHECY.md`

**Per-prophecy entry fields:**
- *Verse reference:* The specific verse(s) containing the prophetic statement
- *What the text says:* The prophetic statement in the TT's own rendering (TEXTUAL — VERIFIED)
- *Context:* Who is speaking, to whom, under what circumstances
- *Subject:* Who or what the prophecy concerns (as stated in the text, not as interpreted)
- *Traditional readings:* Each tradition's reading, labeled with confidence:
  - Jewish reading (LATER RECEPTION — DOCUMENTED)
  - Christian reading (LATER RECEPTION — DOCUMENTED)
  - Islamic reading (LATER RECEPTION — DOCUMENTED, where applicable)
  - Readings within a tradition may disagree — use sub-tradition labels (e.g., "Patristic", "Reformed", "Rabbinic")
- *Scholarly assessment:* The scholarly consensus on whether this is a prophecy, a retrospective interpretation, or a literary device (various confidence levels)
- *Fulfillment status:* FULFILLED (historically documented) | PARTIAL (partially fulfilled per a tradition) | CLAIMED (tradition asserts fulfillment) | UNFULFILLED (no claimed fulfillment) | DEBATED (traditions disagree) | MULTI_STAGE (tradition reads multiple fulfillment phases)
- *Fulfillment notes:* Free-text for partial/multi-stage explanations
- *When fulfilled (if applicable):* Date/period with confidence label

**Critical Rule 3 safeguard:** Prophecy entries MUST distinguish between what the text says (TEXTUAL) and how traditions read it (LATER RECEPTION). "Genesis 3:15 prophesies Jesus" is a CHRISTIAN LATER RECEPTION reading, not a TEXTUAL fact. The text says "enmity between your seed and her seed." The messianic reading is an interpretation — documented, influential, but not the only one.

**Sections follow the AVAILABLE-not-mandatory pattern.** Only chapters containing prophetic material need prophecy files.

**People and Genealogy Files:**

Structured data tracking individuals mentioned in the text.

**Location:** `{locale}/{book}/PEOPLE.md` (one per book; cross-book canonical entries added when multiple books exist)

**Per-person fields:**
- Name (TT transliteration), name meaning/etymology (if given in text)
- Origin type: BORN | CREATED | APPEARS | UNCERTAIN
- Birth year (approximate, with confidence label), death year, lifespan (if stated)
- Father, mother, spouse(s), children (named)
- Location(s), first mention (book:chapter:verse), key events

**Ethnogenesis prohibition:** Linking biblical peoples to modern ethnic groups, nations, or political entities is PROHIBITED unless every link carries archaeological or genetic verification with the corresponding source documented in Section H. Speculative ethnogenesis claims are not permitted regardless of confidence label.

**Book-Level Introductions:**

Book introductions provide historical, compositional, and textual-transmission context at the book level. They follow the same dual-label system and disclaimer requirement as chapter companions.

**Location:** `{locale}/{book}/INTRODUCTION.md`

**Sections follow the AVAILABLE-not-mandatory pattern:** G. Sources Consulted is MANDATORY. A–F are AVAILABLE — include only when there is substantive, sourced content. Strong recommendation to include at least A (Overview) and 2–3 substantive others.

- **A.** Overview
- **B.** Authorship and Composition
- **C.** Dating
- **D.** Historical Setting
- **E.** Manuscript Transmission
- **F.** Reading This Book in the TT
- **G.** Sources Consulted — **MANDATORY**

**Genre-adapted section variations:** When a book's genre differs from narrative, the introduction sections adapt. The required sections (A-G with G mandatory) remain the same, but their content emphasis shifts:

| Genre | Section adaptations |
|-------|-------------------|
| **Narrative** (Genesis, Exodus, Joshua, Judges, Samuel, Kings, Chronicles, Ezra-Nehemiah, Ruth, Esther, Jonah, Acts, Gospels) | Standard A-G as specified above |
| **Poetry & Wisdom** (Psalms, Proverbs, Job, Song of Songs, Ecclesiastes, Lamentations) | Add to D: **Poetic Structure** — parallelism types, acrostic patterns, meter debates. Add to D: **Performance & Liturgical Context** — how these texts were used in worship |
| **Prophecy & Apocalyptic** (Isaiah, Jeremiah, Ezekiel, Daniel, Minor Prophets, Revelation) | Add to D: **Prophetic Tradition** — the prophet's role in ANE and Israel. Add to D: **Apocalyptic Conventions** — genre expectations the original audience brought |
| **Law & Covenant** (Leviticus, Numbers, Deuteronomy) | Add to D: **Legal Genre in the ANE** — comparison with Code of Hammurabi, Hittite treaties. Add to D: **Cultic and Social Institutions** assumed by the text |
| **Letters & Epistles** (Romans through Jude) | Add to B: **Recipient Community** — who they were, what occasion prompted the letter. Add to D: **Epistolary Conventions** — Greco-Roman letter format, rhetorical structure |

A book may belong to multiple genres (e.g., Daniel is both narrative and apocalyptic) — include all relevant adapted sections.

**What the introduction must NOT do:**
- Assert a single authorship model as fact when scholarship is divided
- Present composition theories as settled when they are debated
- Use devotional or homiletic tone
- Preview the book's theological conclusions
- Import later doctrinal frameworks (Rule 3 applies fully)

This decision affects editorial framing and marketing positioning, **NOT** core translation methodology. The Spanish TT is built from source text using TT rules regardless of Reina-Valera stance.

## LANGUAGE-SPECIFIC ADVANTAGES

### **English:**

**Useful Tools:**
- "Shall be" for jussive (formal but effective)
- Slight awkwardness acceptable when mirroring source text
- Word order more flexible than assumed

**Accept Limitations:**
- Lost grammatical gender (note when theologically significant)
- Must add articles frequently (mark additions per Rule 11)
- Limited verb conjugation
- No subjunctive mood for jussive (must use workarounds)

---

### **Brazilian Portuguese (Natural Advantages):**

**Exploit These Strengths:**
- ✓✓ **Subjunctive mood** = perfect for jussive ("Haja luz")
- ✓✓ **Grammatical gender** = preserves source gender naturally
- ✓✓ **Pronoun dropping** = matches source-text compression
- ✓✓ **Gerund** = excellent for participles ("pairando")
- ✓✓ **Flexible word order** = closer to source than English
- ✓✓ **Compression** = can often match source-text compression without additions

**Watch Out:**
- Resist archaic "Bible Portuguese"
- Don't over-import Portuguese Catholic/Protestant Bible tradition vocabulary

**Why Portuguese Excels for TT:**
Portuguese may be the **strongest of the four languages** for this project because subjunctive naturally handles jussive, grammatical gender preserves source distinctions, and compression matches source text better than English or German.

---

### **German (Natural Advantages):**

**Exploit These Strengths:**
- ✓✓ **Konjunktiv (subjunctive)** = can match jussive mood
- ✓✓ **Compound words** = excellent for poetic doubling and construct chains
- ✓✓ **Flexible word order** = closer to source than English
- ✓✓ **Grammatical gender** = can preserve source gender distinctions
- ✓✓ **Article system** = rich enough to track source article distinctions
- ✓✓ **Passive voice** = robust system matches source passive well
- ✓✓ **Participle system** = excellent for aspectual distinctions
- ✓✓ **Case system** = can show grammatical relationships

**Watch Out:**
- **Gender mismatches** with source languages — note when theologically relevant
- **Luther Bible echo** — avoid sounding like translation of tradition
- **Over-compounding** — don't create false precision
- **Capitalization** — all nouns capitalized grammatically, NOT for theological emphasis

---

### **Spanish (Natural Advantages):**

**Exploit These Strengths:**
- ✓✓ **Subjunctive mood** = natural match for jussive ("Haya luz" — living form, no archaic resonance)
- ✓✓ **Grammatical gender** = 2-gender system preserves source gender naturally
- ✓✓ **Flexible word order** = SVO default but VSO/OVS possible
- ✓✓ **Preterite/imperfect distinction** = maps to source-text perfect/imperfect
- ✓✓ **Gerund** = preserves ongoing aspect excellently
- ✓✓ **Pronoun dropping** = moderate (less than Portuguese, more than English)
- ✓✓ **Compression** = few additions needed
- ✓✓ **Passive voice** = robust system with *ser* + past participle

**Watch Out:**
- **Gender mismatches** with source languages — note when theologically relevant
- **Reina-Valera echo** — avoid sounding like translation of RV tradition
- **Archaisms** — "empero," excessive "he aquí," "vosotros" — do not import RV register
- **Regional variation** — use neutral educated pan-Hispanic Spanish
- **YHWH rendering** — must use YHWH, not JHWH (Spanish J=/x/)

**Why Spanish Is Strong for TT:**
Subjunctive naturally handles jussive, grammatical gender preserves source distinctions, preterite/imperfect maps to source aspect, and fewer additions needed than English or German. Largest language community among the four — broadest reach.
