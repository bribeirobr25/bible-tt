## SOURCE-LANGUAGE RULES

### Divine Name Policy (CORE Rule 25 Implementation)

The Tetragrammaton (יהוה, YHWH) is the most contested rendering decision in Hebrew Bible translation. It must be addressed by explicit policy before any text containing it is translated (Genesis 2:4 onward).

**Permitted Renderings (choose one per edition, declare in front matter):**

| Option | EN | PT | DE | ES | Notes |
|--------|-----|-----|-----|-----|-------|
| **A. Consonantal** | YHWH | YHWH | JHWH | YHWH | Maximum transparency; reflects unvocalized text. Recommended **default for Transparent Edition.** **Spanish uses YHWH** (not JHWH) because Spanish J = /x/ (velar fricative), not /j/ (palatal approximant). JHWH would mislead Spanish readers. Y = /j/ in Spanish, correctly representing Hebrew yod. |
| **B. Vocalized scholarly** | Yahweh | Javé | Jahwe | Yahvé | Reconstructed vocalization; scholarly convention. Note: this is reconstruction, not Masoretic. |
| **C. Substitution (traditional)** | the LORD | o SENHOR | der HERR | el SEÑOR | Reflects Jewish *qere* tradition (read *Adonai*). Recommended **only for Reader Edition** with explicit declaration. |
| **D. Adonai transliteration** | Adonai | Adonai | Adonai | Adonai | Honors Jewish reading tradition. |

**Required Behaviors:**
- Edition front matter MUST state which option is in use.
- The choice is **locked per edition** for the entire translation; switching mid-project requires an editorial-log entry and re-alignment review.
- First occurrence in any book gets a 🔴 CRITICAL note explaining the choice and naming the alternatives not taken.
- **Never silently substitute.** "LORD" / "SENHOR" / "HERR" / "SEÑOR" without declaration violates Rules 3, 11, and 22 simultaneously.
- When the text contains *Adonai YHWH* (אֲדֹנָי יהוה), distinguish in main text or note — do not collapse to "Lord GOD."
- *Elohim* (Rule 1, glossary) and *YHWH* are distinct lexemes; never merge.

### Converting Vav (CORE Rule 9 Implementation)

The vav-consecutive (ו) changes future→past in narrative.

**Main Text Policy:**
- Translate into natural past tense in all languages
- Don't force awkward constructions

**Note Policy:**
- Explain at **first important occurrence**
- Brief format: "Converting-vav changes future יְהִי to past"
- "Vav conversivo muda futuro para passado"
- "Vav conversivum wandelt Futur in Vergangenheit"
- "El vav conversivo cambia futuro a pasado"
- Don't repeat explanation every verse

### Hebrew Verb System (extends CORE Rule 8)

**Future-as-Command (Jussive):**
```
Hebrew: יְהִי (yehi) - future form used as command

English Options (pick one consistently per edition):
✓ "Shall be light" (closer to Hebrew form)
✓ "Let there be light" (traditional, acceptable)
Note once: "Hebrew uses jussive/future for divine command"

Portuguese:
✓ "Haja luz" (subjunctive - excellent match)
✓ "Seja luz" (alternative)
Note: "Hebraico usa jussivo para comando divino"

German:
✓ "Es werde Licht" (Konjunktiv I - preserves jussive, slightly archaic feel)
✓ "Es soll Licht sein" (modern construction)
Note: "Hebräisch verwendet Jussiv für göttlichen Befehl"

GERMAN TRANSPARENT EDITION: Konjunktiv I when readable ("Es werde Licht")
GERMAN READER EDITION: Modern construction if Konjunktiv I feels too archaic

Spanish:
✓ "Haya luz" (subjunctive — excellent natural match for Hebrew jussive)
✓ "Que haya luz" (with subjunctive marker — more explicit)
Note: "El hebreo usa el yusivo para el mandato divino"

SPANISH TRANSPARENT EDITION: "Haya luz" (bare subjunctive, closest to Hebrew compression)
SPANISH READER EDITION: "Que haya luz" (with subjunctive marker)
```

**Voice Preservation:**
```
Passive Hebrew verbs → Passive translation in ALL languages
Hebrew: וְתֵרָאֶה (vetei'ra'eh) - passive "be seen"
✓ EN: "and the dry ground shall be seen"
✓ PT: "e a terra seca será vista"
✓ DE: "und das trockene Land werde gesehen" (passive with werden)
✓ ES: "y la tierra seca será vista" (passive with ser + participle)

German has robust passive voice system with werden + past participle
Spanish has robust passive voice with ser + past participle
```

**Participles (Ongoing Action):**
```
Hebrew: מְרַחֶפֶת (merachefet) - present participle
✓ EN: hovering (present progressive)
✓ PT: pairando (gerúndio)
✓ DE: schwebend (Partizip Präsens)
✓ ES: revoloteando (gerundio — ongoing action)
✗ EN: hovered (simple past - wrong aspect)
✗ DE: schwebte (simple past - wrong aspect)
✗ ES: revoloteó (pretérito - wrong aspect)
```

**Spanish Verb System:**
- Preterite/imperfect distinction: "creó" (completed action) vs. "creaba" (ongoing) maps to Hebrew perfect/imperfect
- Gerund system excellent for Hebrew participles (revoloteando, separando, creando)
- Subjunctive naturally handles jussive (living grammatical form, not archaic)

### Hebrew Locked Formulas (extends CORE Rule 7)

**Genesis 1 Locked Formula Patterns:**

**English:**
- "And God said..."
- "And it was so"
- "And God saw that good" / "And God saw that it was good"
- "And was evening, and was morning, [X] day"

**Portuguese:**
- "E Deus disse..."
- "E foi assim"
- "E Deus viu que bom" / "E Deus viu que era bom"
- "E foi tarde, e foi manhã, dia [X]"

**German:**
- **Reader Edition:** "Und Gott sagte..." (elevated contemporary)
- **Transparent Edition:** "Und Gott sprach..." (slightly more elevated; preserves narrative weight)
- "Und es war so"
- "Und Gott sah, dass gut" / "Und Gott sah, dass es gut war"
- "Und es war Abend, und es war Morgen, [X] Tag"

**Spanish:**
- "Y Dios dijo..." (elevated neutral; no *sagte/sprach* distinction needed)
- "Y fue así"
- "Y Dios vio que bueno" / "Y Dios vio que *era* bueno"
- "Y fue tarde, y fue mañana, día [X]"

**Compression Policy:**
- **Transparent Edition:** "that good / que bom / dass gut / que bueno" (preserves compression)
- **Reader Edition:** "that it was good / que era bom / dass es gut war / que era bueno" (minimal addition marked)

### Hebrew Transliterations (extends CORE Rule 4)

**רָקִיעַ (raqia):**
- Keep "raqia" in main text throughout Genesis 1 (Transparent Edition) — ALL LANGUAGES
- First occurrence: "raqia (expanse)" / "raqia (expansão)" / "raqia (Ausdehnung/Gewölbe)" / "raqia (extensión)"
- Define in note: "From root meaning 'to hammer/beat'; describes sky/expanse; verse 8 identifies as 'sky'"
- Reader Edition may use "expanse/expansão/Ausdehnung/extensión" but must preserve "raqia" in notes

**תֹהוּ וָבֹהוּ (tohu vavohu):**
- Optional transliteration when preserving uncertainty
- Use minimal imagistic language: "chaos and void / caos e vazio / Chaos und Leere / caos y vacío"
- Note: "Rare phrase (3x in Bible); meaning debated; associated with destruction/desolation"

### Hebrew Article System (extends CORE Rule 17)

**Basic Rule:**
- Hebrew has article → target language has article
- Hebrew lacks article → don't add (unless target idiom requires)

**Exception: Proper Names**
- ה (ha-) may mark term becoming proper name
- Example: הָאָדָם (ha'adam) = "the human / o humano / der Mensch / el humano" → "Adam / Adão / Adam / Adán" (when becomes name)
- Policy: Flag the shift in a note

**German Article System Extension:**
German has 4 cases (nominative, accusative, dative, genitive) with gendered articles (der/die/das). Hebrew ה → German definite article in appropriate case. Track gender mismatches:
- רוּחַ (fem. Hebrew) → der Wind/der Geist (masc. German) - DOCUMENT
- מַיִם (masc. plural Hebrew) → das Wasser (neut. singular German) - DOCUMENT
- אֶרֶץ (fem. Hebrew) → das Land (neut. German) - DOCUMENT when relevant

**Spanish Article System:**
Spanish has gendered articles (el/la/los/las). Hebrew ה → Spanish definite article in appropriate gender. Track gender mismatches:
- רוּחַ (fem. Hebrew) → el viento/el espíritu (masc. Spanish) - DOCUMENT
- תְהוֹם (fem. Hebrew) → el abismo (masc. Spanish) - DOCUMENT
- אֶרֶץ (fem. Hebrew) → la tierra (fem. Spanish) - matches, no issue

### Masoretic Text Layers (CORE Rule 26 Implementation)

The Masoretic Text is itself a layered tradition. The translator must declare which layer is being rendered.

**A. Consonantal text (ketiv):**
- Authoritative base layer.
- Where *ketiv* and *qere* diverge meaningfully, translate the **ketiv** in main text and note the **qere**.
- Exception: where *ketiv* is grammatically impossible or scribal-error consensus exists, follow *qere* and note the *ketiv* in Tier 2.

**B. Tiberian vocalization (Masoretic pointing, ~10th c. CE):**
- Treated as **the primary received reading tradition**, not as part of the consonantal text.
- Where vocalization forces a contested interpretive choice, note the alternative vocalization possibility in Tier 2 with an uncertainty level (Rule 13).

**C. Cantillation (te'amim):**
- Used to inform syntactic parsing (especially *athnach*, *zaqef*, *silluq* as clause-boundary markers).
- Where cantillation suggests a parsing different from common modern translations, follow cantillation in main text and note the alternative.

**D. Versional variants (LXX, Samaritan Pentateuch, DSS, Targumim, Peshitta, Vulgate):**
- Per Rule 22: noted, never silently adopted.
- Significant variants get a Tier 2 or Tier 3 note with siglum (𝔊, 𝔐, 𝔖𝔓, 4QGen-Exod^a, etc.) and BHS/BHQ apparatus reference.

**Citation format for source text:**
- BHS: `BHS, 5th rev. ed. (Stuttgart: Deutsche Bibelgesellschaft, 1997), p. <n>.`
- BHQ: `BHQ, fascicle <name>, ed. <name> (DBG, <year>), p. <n>.`

The LXX is treated here as a textual witness to the Hebrew base text. When the LXX is referenced as a Greek source-text in its own right (e.g., NT quotation analysis), see RULES-GS.md.

### No-Harmonization — Hebrew Examples (extends CORE Rule 22)

Translation of a verse must be governed first by its **immediate Hebrew context** and **book-level patterning**, not by later canonical harmonization or doctrinal back-reading.

This means:
- Do not translate Gen 3:15 to match New Testament Christology.
- Do not translate Gen 1:2 *ruach* to match later pneumatology.
- Do not translate Gen 2:17 *beyom* to match Gen 5:5 death-timing.
- Each verse answers to its own text first. Cross-canonical resonance belongs in notes (Tier 2) or appendix (Tier 3), never in the main translation.

### Hebrew Gender Tracking (extends CORE Rules 16, 17, 27)

**German-specific mismatches:**
- רוּחַ (fem.) → Wind/Geist (masc.) - NOTE when theologically relevant
- תְהוֹם (fem.) → die Tiefe (fem.) - matches Hebrew, no issue
- Document all mismatches in editorial log

**Spanish-specific mismatches:**
- רוּחַ (fem.) → el viento/el espíritu (masc.) - NOTE when theologically relevant
- תְהוֹם (fem.) → el abismo (masc.) - NOTE gender mismatch
- אֶרֶץ (fem.) → la tierra (fem.) - matches Hebrew, no issue

**Hebrew Gender Specifics (Rule 27):**
- **Generic *adam*:** "human / humano / Mensch / humano" (per glossary). "Man / homem / Mann / hombre" only when contrasting with *ishah*.
- **Ish and ishah:** Gendered pair → gendered pair: "man/woman," "homem/mulher," "Mann/Frau," "hombre/mujer."
- **Zakhar u-neqevah** (Gen 1:27): "male and female / macho e fêmea / männlich und weiblich / varón y hembra." NOT "man and woman" — Hebrew uses biological-pair terms, not social terms.
- **Collective singulars** (e.g., *zera* = "seed/offspring"): Follow Hebrew grammatical agreement in main text (masculine singular → "he" in English). Note must flag collective scope. Do not capitalize "He" for Christological individuation.

## ARAMAIC APPENDIX

Small sections of the Hebrew Bible are written in Aramaic rather than Hebrew:

- **Daniel 2:4b–7:28** — court tales and visions
- **Ezra 4:8–6:18 and 7:12–26** — official correspondence
- **Genesis 31:47** — two words (*yegar sahaduta*, Laban's name for the stone heap)
- **Jeremiah 10:11** — one verse (declaration against false gods)

Aramaic is a related Semitic language sharing much grammar with Hebrew. For these passages:
- The same TT principles apply (Prime Directive, Rules 1-29)
- Aramaic-specific verb forms and constructions should be noted in Tier 2
- The base text remains BHS/BHQ (Aramaic sections are included in the Masoretic tradition)
- Transliteration follows the same conventions as Hebrew terms
- The source-analysis method applies unchanged (`../source-analysis/METHOD.md`); Aramaic worked examples are archived at `../source-analysis/aramaic/`, and this appendix is their governance home — there is no separate RULES-Aramaic file
