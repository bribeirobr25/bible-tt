# Glossary proposal — bare נֶפֶשׁ (*nephesh*)

**Date:** 2026-11-20 · **Ruleset:** v3.4.1 · **Status:** landed in **§G3 Hybrid mode** (no calendar window). Provisional pending the Hebraist and the locale editors (Rule 28), who may flag it for revision after landing.
**Decision source:** project lead, D7 (2026-11-19, `docs/audit/LAUNCH_PROGRAM.md`): ψυχή / נֶפֶשׁ locked **life/being**, cross-supplement aligned.

| Field | Content |
|---|---|
| Source-language form | נֶפֶשׁ (*nephesh*), bare — not the compound נֶפֶשׁ חַיָּה, which keeps its own row ("living being(s)") |
| Transliterated form | *nephesh* (cited as a lemma only; not transliterated in the text) |
| Proposed renderings | EN life/being · PT-BR vida/ser · DE Leben/Wesen · ES vida/ser — **a pair, not a slash**: the context selects the member (CORE §I3). A Rule 2 slash `{a:life/being}` only where both senses are live, logged. |
| Cross-supplement alignment | GS ψυχή = life/being (RULES-GS glossary, "MUST match HB rendering"; cross-supplement table). §G4 requires the aligned term in both supplements; the HB side had only the compound. |
| Editorial-log entries triggered | `genesis.md` 2026-11-20-122 (this row); `acts.md` A-010, `luke.md` L-006, `1-peter.md` D7 note (GS side). |
| Affected verses | Genesis 1–12 bare-nephesh contexts named in the current notes: **9:4** ("flesh with its *nephesh*" — EN already "life", inside the pair), **9:5** (the life of the human), **12:5** ("the *nephesh* they had made" — EN "persons": outside the pair → Rule 1 deviation), **12:13** ("my *nephesh*" — "my life"). The full occurrence list is verified against the base text (BHS) in Step 4 batch 4 with the D7 sweep. |
| Justification | The lead's D7 lock; the post-Platonic "soul" imports a body/soul dualism the Hebrew does not carry (the same reason the compound row already gives). |
| Alternatives considered | "soul" — rejected (D7; the compound row's note). No HB row, leaving the GS "MUST match" pointing at nothing — rejected (§G4). A mandatory slash `life/being` in the text — rejected: it would print a slash at every occurrence. Rule 2 slashes are for ambiguity the source keeps, and these contexts usually select one sense. |
