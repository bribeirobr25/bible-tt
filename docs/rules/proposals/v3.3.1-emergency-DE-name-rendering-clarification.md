## Rationale

DE chapter files (Matthew 1-3, John 1-3, Genesis 1-12) were authored using a pattern that violates the existing §PROPER-NAME TABLE note rule "Names where the familiar form is identical to the transliterated form ... use the transliterated form throughout — no parenthetical needed." Specifically, DE files produced 335 occurrences of `Name (Name)` (identical-word in parens) — visually redundant first-occurrence flags that the existing rule already implicitly prohibits but did not explicitly call out for the cross-locale case where `<Translit>` and `<DE Familiar>` may differ.

The author's working assumption appears to have been that the first-occurrence convention required parens on EVERY proper name regardless of whether the translit-form and familiar-form actually differ. The DE Matthew 1 KAPITELÜBERSICHT line 42 self-documented this (incorrect) convention: *"Eigennamen folgen der TT-Transliteration: Jesus, Josef (Josef), Maria (Maria), Abraham usw."* — citing `Jesus` and `Abraham` (bare German familiars) as if they were TT-transliterations, while doubling `Josef (Josef)` and `Maria (Maria)` in redundant parens despite the actual TT-transliterations being `Yosef` and `Miryam`.

The remediation sweep (executed 2026-05-18 per `docs/audit/DE_FAMILIAR_NAMES_PLAN.md`) corrected 259 in-scope occurrences across 17 DE chapter files + 1 study file. The remaining 76 occurrences are in out-of-scope sections (GLOSSAR lookup tables, KAPITELÜBERGREIFENDE VERFOLGUNG cross-chapter tracking tables) where the redundant-parens pattern has table-cell semantics distinct from prose. This amendment codifies the rule clarification so future DE authoring does not repeat the mistake.

## Affected rules / interaction with existing policy

- **CORE Rule 17 (name rendering):** unchanged — the first-occurrence convention ("Transliterated (Familiar)" at first occurrence per section, familiar-only thereafter) is preserved exactly.
- **RULES-HB.md §PROPER-NAME TABLE notes:** the existing rule on "no parenthetical needed when translit == familiar" is preserved; this amendment adds an explicit bidirectional clarification for the DE-locale case.
- **RULES-GS.md §PROPER-NAME TABLE — GREEK SCRIPTURES:** unchanged. The amendment refers to it for the cross-locale NT-name case but adds no rules to GS.
- **No existing rules are modified.** This is an additive clarification only.
- **No signed-off verses are affected.** All DE Matthew/John/Genesis chapters are `provisional` status.

## Draft amendment text (append to RULES-HB.md §PROPER-NAME TABLE — GENESIS 1-12 notes section)

```markdown
- **DE-locale clarification (v3.3.1 amendment, 2026-05-18):** The no-parenthetical-needed rule applies bidirectionally for German. When `<Translit> == <DE Familiar>` (e.g., `Adam`, `David`, `Andreas`, `Nathanael`, `Herodes`), the bare form is used throughout — no parens at first occurrence, no parens at subsequent occurrences. When `<Translit> != <DE Familiar>` (e.g., Hebrew `Avraham` / DE `Abraham`; Hebrew `Yerushalayim` / DE `Jerusalem`; Greek `Yeshua` / DE `Jesus`), the form is `<Translit> (<DE Familiar>)` at first occurrence per `^## ` section, then `<DE Familiar>` only thereafter. The same convention applies for GS-source NT names, governed by the RULES-GS.md proper-name table. **Never** produce a redundant `Name (Name)` form where the parenthetical word is identical to the leading word — this is the specific pattern this amendment forbids.
```
