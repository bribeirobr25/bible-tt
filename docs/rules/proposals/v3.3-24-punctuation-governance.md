# Proposal: §Punctuation Governance

**Target:** RULES-CORE.md
**Source feedback item:** FEEDBACK.md item 24 (AGREE — no dedicated punctuation rule exists; only incidental mentions on lines 489 and 690)
**Lock-Protocol path:** Hybrid (Emergency-with-proposals) — see `docs/audit/FIX_IMPLEMENTATION.md` Phase 5.5
**Proposed for:** Ruleset v3.3
**Status:** drafted 2026-05-08

---

## Rationale

The TT currently has no governing rule on punctuation. The audit flagged this as a real gap: punctuation choices materially affect reader interpretation, especially around quotation boundaries (e.g. Jn 3:16–21), em-dash usage (narrative breaks vs. date ranges), Spanish minimal-pair accents, and German nominative-case capitalization. Without a policy, locale editors make ad-hoc choices that drift across the corpus.

The Phase 2C em-dash sweep cleared 3,583 raw `--` instances — but only because the editorial team agreed informally on em-dash convention. The same informal agreement governs other punctuation choices that future content will face. A documented policy locks the convention and gives reviewers a reference.

## Affected rules / interaction with existing policy

- **Prime Directive:** punctuation is part of "what the source text keeps." When the source uses no quotation marks (Hebrew/Greek did not), adding them resolves boundaries the source leaves open.
- **Rule 5 (literal-form preservation):** speech-boundary policy directly intersects with literal preservation — quoting `John 3:16–21` as Jesus's speech vs. narrator commentary settles a debate the Greek leaves open.
- **Rule 21 (no commentary smuggled into main text):** typography is a form of commentary.
- **No rules are modified.** This is a new universal policy.

## Draft text (insert after Rule 29, before §EDITORIAL LOG SPECIFICATION)

```markdown
## §PUNCTUATION GOVERNANCE

Punctuation choices are interpretive. The TT sets the following conventions to prevent typography from resolving ambiguity the source text preserves.

### §P1. Em-dash convention

- **Em-dash (—, U+2014)** for narrative breaks, mid-sentence asides, and parenthetical clarifications in main text.
- **Two hyphens (`--`)** in raw markdown source ARE permitted ONLY in: (a) date/verse ranges (`Gen 5:21–27`); (b) markdown horizontal rules (`---`). All other ` -- ` instances are bugs.
- Lint rule §0.2 in `scripts/content-lint.sh` enforces this.

### §P2. Speech boundaries (Tier 1 main text)

- The Hebrew and Greek source texts use no quotation marks. The TT inserts quotation marks **only where the source unambiguously marks speech** through narrative framing (e.g. "X said:"). When the boundary is debated (e.g. where Yeshua's discourse ends and the narrator's commentary begins in Jn 3:16–21, Jn 3:31–36), main text uses quotation marks for the narrowest defensible boundary, with a Tier 2 note flagging the alternative.
- Locale-specific quotation conventions: EN/ES use `"…"`; PT-BR uses `"…"` (modern); DE uses `„…"` (lower-then-upper). All four are acceptable; do not mix within a chapter.

### §P3. Comma and semicolon

- Use commas to separate items in narrative lists; use semicolons to separate items where each contains internal commas or where the items are clausal.
- Do NOT use commas to resolve grammatical ambiguity the source preserves (e.g. attaching a phrase to one antecedent over another).

### §P4. Spanish minimal-pair accents

Spanish has minimal pairs distinguished only by an acute accent: `el/él`, `mas/más`, `tu/tú`, `mi/mí`, `que/qué` (interrogative vs. relative), `como/cómo`, `cuando/cuándo`, `donde/dónde`. The TT main text MUST mark the accented form whenever the word functions as the accented sense; absence is a bug, not a stylistic choice. Lint rule §0.3 (ES NT diacritic loss) enforces a subset; broader compliance is an editor responsibility.

### §P5. German verb-period and capitalization

- German nouns are grammatically capitalized — this is NOT theological capitalization (Rule 20 exemption is documented in `RULES-CORE.md` Rule 20 and Phase 1 audit closure).
- German final periods after dependent clauses follow standard convention; the TT does not impose abnormal punctuation patterns even in elevated register.

### §P6. Editorial-log entry trigger

A new editorial-log entry is required when:
- A non-default quotation boundary is chosen for a debated passage.
- A locale-specific punctuation choice diverges from cross-language alignment (Rule 16).
```

## Impact assessment

- **Affected signed-off verses:** none (all current TT content is `provisional` per Rule 28; no signed-off verses exist).
- **Affected provisional verses:** all currently-authored Genesis 1–12, John 1–3, Matthew 1–3 chapters across 4 locales already comply with §P1 (em-dash sweep complete). §P2 may surface speech-boundary cases that need review (e.g. Jn 3:16–21). §P3–§P6 are codifications of existing practice.
- **Migration cost:** zero immediate; review pass during next Rule-28 cycle should confirm §P2 boundaries.

## Why Hybrid (Emergency-with-proposals)

The proposal artifact preserves the discipline; the absent window saves calendar time.
