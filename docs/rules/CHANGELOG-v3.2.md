# Changelog — Ruleset v3.1 → v3.2

**Date:** 2026-05-06
**Amendment type:** Emergency Amendment (audit-driven accessibility improvement)
**Rationale:** Transliterated names as default created a persistent decoding burden for readers. Familiar-form default dramatically improves reading experience while preserving source-text transparency at first occurrence. No signed-off verses affected.

---

## RULES-CORE.md

| Addition | Description |
|----------|-------------|
| **Name rendering policy** | Familiar target-language names as default after first-occurrence gloss. Transliterated form shown once per section with familiar form in parentheses. Exceptions: YHWH/JHWH (Rule 25), Yehudim (Ioudaioi Policy), technical transliterations (Rule 4). |
| **Group name policy** | All group names get familiar-form treatment except Yehudim. Perushim → Pharisees, Tsduqim → Sadducees, etc. |

## RULES-HB.md

| Change | Description |
|--------|-------------|
| **Proper-name table expanded** | Added "Familiar Form" columns for all 4 locales. Added Genesis 1-3 names (Adam, Chava), place names (Yerushalayim, Yarden, Mitsrayim, etc.), group names, and HB person names referenced in GS (Mosheh, Eliyahu). Table now covers all names in Genesis 1-12. |

## RULES-GS.md

| Addition | Description |
|----------|-------------|
| **GS proper-name table** | New table for names unique to Greek Scriptures: 13 person names + 3 place names with familiar forms in all 4 locales. |
