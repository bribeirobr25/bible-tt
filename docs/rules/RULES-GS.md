## DIVINE NAME POLICY — κύριος IN OT QUOTATIONS

When the Greek Scriptures quote or allude to Hebrew Bible passages containing the Tetragrammaton (יהוה, YHWH), the Greek text uses κύριος (*kyrios*, "lord/master"). The TT policy for handling this:

**Policy: Option C — Translate Greek base text + mandatory note**

| Option | EN | PT | DE | ES | Notes |
|--------|-----|-----|-----|-----|-------|
| A. Retrovert | YHWH | YHWH | JHWH | YHWH | Translates what is NOT in the Greek base text. Violates Rule 1 + Rule 22. |
| B. Greek only | the Lord | o Senhor | der Herr | el Señor | Faithful to base text. Conceals the OT connection. |
| **C. Translate + note** | **the Lord** | **o Senhor** | **der Herr** | **el Señor** | **ADOPTED.** Translates base text (Rule 1, 22). Notes OT YHWH connection (Rule 14). |

**Rationale:** The GS base text is Greek. The Greek says *kyrios*. Rule 1 (source-text fidelity) requires translating what the text says. No extant Greek NT manuscript contains the Tetragrammaton. Placing YHWH in the main text would translate a word that is not there — a Rule 22 violation. The OT YHWH connection belongs in a note per Rule 14 (cross-references).

**Required behaviors:**
- Edition front matter MUST state this policy.
- First occurrence in any book gets a 🔴 CRITICAL note explaining the policy and naming the alternatives not taken.
- When quoting an OT passage that contains YHWH: note MUST identify the OT source and state that the underlying Hebrew has the Tetragrammaton.
- When *kyrios* refers to Jesus or a human lord (not an OT YHWH quotation): no YHWH note needed.
- The distinction must be tracked per verse. Ambiguous cases (where the referent of *kyrios* is debated) are flagged per Rule 13.

## GREEK VERB/ASPECT SYSTEM (extends CORE Rule 8)

Greek verbal aspect differs fundamentally from the Hebrew tense system. The primary distinction is *aspect* (how the speaker views the action), not *time* (when the action occurs).

**Aorist (Undefined Aspect):**
```
Greek: ἐποίησεν (epoiesen) — aorist indicative
Main text: translate as simple past in all languages
Note at first occurrence: "Greek aorist views the action as a whole,
without specifying its internal structure"
EN: "he made" / PT: "ele fez" / DE: "er machte" / ES: "él hizo"
```

**Present (Ongoing/Repeated):**
```
Greek: πιστεύει (pisteuei) — present indicative
Main text: translate as ongoing present
Note when aspect is theologically significant
(e.g., John 3:16 πιστεύων = "the one trusting" — ongoing, not one-time)
EN: "trusts" / PT: "confia" / DE: "vertraut" / ES: "confía"
```

**Perfect (Completed with Ongoing Result):**
```
Greek: γέγραπται (gegraptai) — perfect passive
Main text: "it has been written" / "está escrito" / "es ist geschrieben" / "está escrito"
Note: "Greek perfect emphasizes the ongoing authority of the completed writing act"
```

**Middle Voice (Subject Acts on/for Itself):**
```
Translate with reflexive or self-interest constructions where possible.
Note at first occurrence when middle voice carries theological weight.
```

**Subjunctive (Potential/Probable):**
```
Maps well to PT/ES/DE subjunctive systems.
English requires periphrasis ("might," "may," "should").
Note when subjunctive vs. indicative choice is exegetically significant.
```

**Key principle:** Do NOT import the Hebrew time-based framework (past/present/future) into Greek. Greek aspect (how the speaker views the action) is the primary system. Time is secondary and determined by context + indicative mood, not by verbal form alone.

## GREEK TEXTUAL TRADITION LAYERS

The NA28 apparatus draws on multiple manuscript families. The TT policy:

**Translate NA28 main text. Note significant variants in Tier 2.**

### Manuscript Categories

| Category | Sigla | Date Range | Examples |
|----------|-------|------------|---------|
| Papyri | 𝔓 (P-series) | 2nd–7th c. CE | 𝔓46, 𝔓66, 𝔓75 |
| Majuscules | Letters/symbols | 4th–9th c. CE | א (Sinaiticus), A (Alexandrinus), B (Vaticanus), D (Bezae) |
| Minuscules | Numbers | 9th–15th c. CE | f1, f13 (families) |
| Lectionaries | 𝔩 (l-series) | Various | Liturgical excerpts |
| Church Fathers | Abbreviations | 2nd–5th c. CE | Cited readings in patristic literature |
| Byzantine/Majority | 𝔐 | Various | The majority reading across late manuscripts |

### Significance Threshold

A variant is "significant" (and MUST be noted in Tier 2) when ANY of these apply:
1. It affects the meaning of the passage (not orthography or movable-nu)
2. It has support from early papyri or major majuscules (א, A, B, D)
3. It is widely known to readers from other Bible translations

## GS-SPECIFIC GENRE RULES (extends CORE Rule 23)

### A. Gospel Narrative + Discourse

**Narrative sections:** Same treatment as HB narrative. Locked formulas for repeated patterns ("and he said to them," "and he answered and said," miracle-story structures).

**Discourse sections** (Sermon on the Mount, Olivet Discourse, Farewell Discourse): Flag shifts from narrative to teaching voice. Do not smooth discourse structure to match modern essay form.

**Parables:** Flag with a note at opening ("parable begins"). Do not decode symbolic elements in main text. Allegorical interpretations belong in Tier 3 companion files only.

### B. Epistolary

**Locked formulas:** Greetings ("grace and peace" / "graça e paz" / "Gnade und Friede" / "gracia y paz") and closings locked across all epistles.

**Rhetorical structure:** Preserve chiasm, inclusio, and diatribe structure. Note in Tier 2 when these affect translation choices.

**Sentence length:** Do not break Paul's long Greek sentences into short target-language sentences without noting the restructuring per Rule 11.

### C. Apocalyptic (Revelation)

**Symbolic numbers and images:** Translate literally. "Seven" stays "seven," not "completeness." Do not decode symbolism in main text.

**OT allusion density:** Revelation alludes to the OT constantly but rarely quotes directly. Cross-references (Rule 14) flag OT echoes but cap interpretive cross-references at 0–2 per verse per existing policy.

**Liturgical formulas:** Lock them (parallel to Genesis 1 creation formulas).

### D. Acts (Historical Narrative)

**Narrative:** Treat like gospel narrative for methodology.

**Speeches:** Same discourse treatment as gospel discourse.

**Western text variants (Codex Bezae):** Particularly significant for Acts. Tier 2 notes for major Western variants.

## CROSS-SUPPLEMENT GLOSSARY ALIGNMENT

When the same concept appears in both HB and GS, the HB glossary governs the target-language rendering. The GS glossary must use the same English term or justify divergence in the editorial log.

**Confirmed mappings:**

| GS Term | HB Term | Locked EN | Alignment |
|---------|---------|-----------|-----------|
| πνεῦμα *pneuma* | רוּחַ *ruach* | wind/spirit | MUST match — same slash policy |
| διαθήκη *diatheke* | בְּרִית *berit* | covenant | MUST match |
| ἄβυσσος *abyssos* | תְהוֹם *tehom* | the deep | MUST match |
| ψυχή *psyche* | נֶפֶשׁ *nephesh* | life/being | MUST match |
| ἁμαρτία *hamartia* | חַטָּאת *chattat* | sin | MUST match |
| εἰρήνη *eirene* | שָׁלוֹם *shalom* | peace | MUST match |
| δόξα *doxa* | כָּבוֹד *kavod* | glory/weight | MUST match (add to HB glossary when *kavod* passages are reached) |

**Permitted divergence:** Where the Greek semantic range genuinely differs from the Hebrew (e.g., *logos* has philosophical connotations that Hebrew *davar* does not), divergence is permitted but must be logged with specific semantic evidence.

## CROSS-SUPPLEMENT REFERENCES

When a GS chapter contains substantive references to specific HB passages, include a "Cross-Chapter Tracking (HB → GS)" section in the chapter file.

**When to include:** Whenever the GS text directly quotes, clearly alludes to, or structurally parallels a specific HB passage. Not for vague thematic connections.

**Format:** Same parallel-table format used in Genesis cross-chapter tracking sections:
- Direct quotations: marked with "quotes" label and the HB verse reference
- Allusions: marked with "alludes to" label
- Structural parallels: marked with "parallels" label

**Cross-language alignment:** The same tracking sections must appear in all 4 locales with structurally parallel content (Rule 16).

## GS IMPLEMENTATION WORKFLOW

Per-verse steps for Greek source text (parallel to HB workflow):

1. **Read NA28 main text** for the verse
2. **Check apparatus** for significant variants
3. **Identify glossary terms** — render per locked glossary
4. **Check cross-supplement alignment** for any HB-mapped terms
5. **Translate** into all 4 target languages, respecting verb aspect and genre rules
6. **Add Tier 2 notes** — at minimum: glossary explanations at first occurrence, variant notes, aspect notes, *kyrios*/YHWH notes where applicable
7. **Verify Rule 11 markers** — italic for grammatical additions
8. **Cross-language alignment check** (Rule 16) — all 4 languages rendering the same Greek consistently
