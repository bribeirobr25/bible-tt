Governance · Ruleset v3.3

The 29 Rules.

Every translation makes choices. Most hide them. We wrote ours down.

The Prime Directive

If any rule conflicts with these four principles, the principles win.

i

If the original text is complex, we keep it complex.

ii

If the original text is ambiguous, we keep it ambiguous.

iii

We do not add words the source text does not say — unless the target language physically cannot form a sentence without them.

iv

When we do add a word, we mark it so you can see it.

/

Rules in action

A few, made concrete

Rule 1 · Controlled consistency

Hebrew אֶרֶץ (eretz) always → land. Greek ἐκκλησία (ekklesia) → assembly, not “church.”

Rule 2 · Preserve ambiguity

Hebrew רוּחַ (ruach) → wind/spirit. Greek πίστις (pistis) → trust/faithfulness.

Rule 3 · Avoid imported theology

Hebrew: sky, not ‘Heaven.’ Greek: assembly, not ‘church.’ Good news, not ‘Gospel.’

Rule 11 · Signal all additions

“And God saw that it was good” — italics show ‘it was’ is added for English grammar.

Rule 25 · Divine name

YHWH — because that is what the Hebrew consonants are. The vowels were never written.
