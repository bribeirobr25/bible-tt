# Greek source-analysis corpus

Worked examples: `mark-1.md`, `mark-2-3.md` (the Mark pilot; NA28 base text). Extended as further Greek books are authored.

**Governance home:** `docs/rules/RULES-GS.md` (Greek Scriptures supplement). Method: `../METHOD.md`.

**Adaptation hooks** (from `../METHOD.md` §4): analyze by **lemma + inflection** (tense·voice·mood / case·number·gender), not by Semitic root; the verb system is **aspect-primary** (aorist/present/perfect), not tense; the **article's presence/absence is meaningful** (GS §Greek Article System); attestation corpus is NT + LXX (LXX with care). **No living Koine comparand** — Modern/Patristic Greek may only generate hypotheses, never evidence meaning (METHOD.md §4 caution).

**Rule 28:** any Greek worked example is an AI-assisted draft **pending Hellenist review** until a source-language scholar is appointed.
