# Luke 1–3 — source-analysis notes (Greek)

**Method:** `../METHOD.md`. Internal working notes — see `../README.md`. Base text NA28; variant data from its apparatus. **Rule 28:** AI-assisted draft pending Hellenist review.

**Macro:** Luke opens with a formal literary prologue (1:1-4, a single periodic Greek sentence — the most "classical" Greek in the gospels), then shifts to a Septuagintal narrative register for the infancy account (1:5–2:52). Two annunciations in parallel (Yochanan to Zecharyah; Yeshua to Miryam); four canticles in elevated Hebraic-Greek poetry. Luke 3 = Yochanan's wilderness ministry + Yeshua's immersion + the genealogy (3:23-38, ascending Yeshua→Adam, distinct from Matthew's descending Avraham→Yeshua).
