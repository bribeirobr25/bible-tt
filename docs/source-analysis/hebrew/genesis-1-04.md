# Genesis 1:4 — source-analysis notes

**Source:** וַיַּרְא אֱלֹהִים אֶת־הָאוֹר כִּי־טוֹב וַיַּבְדֵּל אֱלֹהִים בֵּין הָאוֹר וּבֵין הַחֹשֶׁךְ
**Method:** `../METHOD.md`. Internal working notes — see `../README.md`.

**Macro:** First verse to deviate from plain word order. The order is arranged so that *ki tov* ("that good") stands as a fixed unit that recurs through the chapter; a "standard" rendering would drop *et*, move *ki*, and re-invert the verb.

### vayar — וַיַּרְא
- **Morphology:** root *r-ʾ-h* "see"; the short/biblical form (vs. standard *yireh*), only ever with the **converting-vav** → "and he saw," 3ms past.
- **Smoothed:** "And God saw." **TT status:** converting-vav.

### et ha-or — אֶת־הָאוֹר
- *et* (object marker, see `genesis-1-01.md`) + *ha-* "the" + *or* "light" → "the light."

### ki-tov — כִּי־טוֹב
- **Morphology:** *ki* + *tov* "good." Here *ki* = "that" (complementizer), one of its several senses (most often "because"; also "when," emphatic, "although" — see `hebrew-word-studies.md` §ki).
- **Range/compression:** "that good" — Hebrew omits the copula. **Smoothed:** "that it was good" (mark "it was" as added, Rule 11).
- **TT status:** "ki tov" locked compression formula (Rule 7); recurs in the chapter.

### vayavdel — וַיַּבְדֵּל
- **Morphology:** root *b-d-l*; short form + converting-vav → "and he separated," 3ms past (standard *yavdil*).
- **Range:** "separate / divide / distinguish." Best = **separate**, supported by the parallel use in the next paragraph.
- **TT status:** Tier 2 note on the range; "separate."

### bein…uvein — בֵּין…וּבֵין
- **Morphology:** *bein* "between" + *u-vein* "and between" — the Hebrew "between X and between Y" frame (useful for grouping lists).
- **Smoothed:** "between the light and the darkness" (the second "between" is idiomatic, not doubled in target).
- **TT status:** structure preserved (Rule 5); note the frame.

### ha-or / ha-choshech — הָאוֹר / הַחֹשֶׁךְ
- "the light" / "the darkness" — both covered above and at `genesis-1-02.md`.
